# Textes alternatifs à relire

Inventaire des images de la médiathèque sans texte alternatif ; toutes ne sont pas nécessairement utilisées. Une image décorative peut conserver un texte alternatif vide. Pour une œuvre informative, décrire brièvement ce qui est visible, avec validation de l’artiste. Le nom de fichier n’est pas une description. Ne pas modifier les fichiers pour remplir ce champ : utiliser Médias → Bibliothèque → image → Texte alternatif. La traduction anglaise des textes alternatifs n’est pas encore gérée par le plugin.
